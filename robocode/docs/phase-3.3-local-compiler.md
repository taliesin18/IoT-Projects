# Phase 3.3 — Local Wi-Fi compiler

## Goal

Compile the Arduino sketch generated by RoboCode blocks, return the complete ESP32 firmware package to the Android app, and use the native OTG flasher already verified in Phase 3.2.

## Decision

The Android SDK is not an ESP32 Arduino compiler. Rather than embedding a large Android-specific toolchain in the first prototype or sending student code to a cloud service, Phase 3.3 runs the existing Arduino CLI and ESP32 board package on the prepared PC. The Android app reaches that compiler only over the same local Wi-Fi network.

```text
Blockly blocks
  → generated .ino in RoboCode
  → local Wi-Fi compiler on PC
  → matched bootloader + partitions + OTA selector + app .bin files
  → RoboCode Android app
  → USB OTG flasher
  → ESP32
```

This is a development-stage bridge, not the final phone-only compilation design. The compile service is intentionally scoped to the classic ESP32 profile `esp32:esp32:esp32` used by the existing CP2102 board.

## Start the compiler on the PC

From `robocode/web` in PowerShell:

```powershell
$env:ARDUINO_CLI_PATH = 'C:\work\local\tools\arduino-cli\arduino-cli.exe'
$env:ARDUINO_CLI_CONFIG = 'C:\work\local\tools\arduino-cli\arduino-cli.yaml'
npm run compiler
```

The service prints a **Phone URL** and temporary **Access token**. Keep that terminal open. Windows may ask for firewall permission; allow Node only on your **Private** home/classroom network.

For a stable token across restarts, set `ROBOCODE_COMPILER_TOKEN` before starting the service. The compiler accepts one job at a time and deletes each temporary sketch/build directory when the build completes.

## Use it from the Android app

1. Put the phone and PC on the same trusted Wi-Fi network.
2. Connect the ESP32 through OTG, open **Hardware**, and choose **Check ESP32**.
3. Allow USB access for the CP2102 device.
4. Under **Compile blocks and flash**, enter the Phone URL and Access token, then choose **Check compiler**.
5. Choose **Compile blocks & flash**.
6. Open Serial Monitor at 115200 baud after the board restarts.

The Android **debug** APK permits HTTP solely to make this trusted-LAN development workflow possible. Do not expose the compiler port to the public internet, do not use it on untrusted Wi-Fi, and use HTTPS before any production deployment.

## Firmware package

The service uses Arduino CLI's `--output-dir` build output and returns the exact matching segment set:

| Segment | Offset |
| --- | ---: |
| Bootloader | `0x1000` |
| Partition table | `0x8000` |
| OTA selector | `0xe000` |
| Application | `0x10000` |

The ESP32 core's `boot_app0.bin` is located from the configured Arduino data directory. If automatic discovery is unavailable, set `ROBOCODE_BOOT_APP0_PATH` to that file's full path.
